# Self-Validation Guide: Slotegrator

## Prerequisites

1. **ngrok** installed and configured
2. **PostgreSQL** running with your database
3. **Redis** running (if needed)
4. **Node.js** with npm

---

## Step 1: Update Environment Variables

Make sure your `.env` file has the correct values:

```env
CASINO_MERCHANT_ID=dbb46701285c1a2e24a0bf92f00501e5
CASINO_MERCHANT_KEY=b83d51ea35e2620a4e29913a9059e8e5038caa64
CASINO_API_BASE_URL=https://staging.slotegrator.com/api/index.php/v1
CASINO_CALLBACK_URL=https://bozcallback.ngrok.app/api/casino/callback
CASINO_TEST_AREA_URL=https://boztestarea.ngrok.app
CASINO_DEFAULT_CURRENCY=USD
```

---

## Step 2: Start ngrok

Open a terminal and run:

```bash
ngrok http 3000
```

**Important:** Copy your ngrok URL (e.g., `https://abc123.ngrok.app`)

---

## Step 3: Update Slotegrator Callback URL

Contact your Slotegrator integration manager and ask them to update the callback URL to:

```
https://YOUR_NGROK_URL/api/casino/callback
```

For example:

```
https://bozcallback.ngrok.app/api/casino/callback
```

---

## Step 4: Start the Project

In a new terminal, run:

```bash
npm run dev
```

Wait until you see:

```
ready - started server on 0.0.0.0:3000
```

---

## Step 5: Create Active Game Session

You need an active game session within 15 minutes of running self-validation.

### Option A: Using cURL

```bash
curl -X POST "http://localhost:3000/api/casino/games/init" \
  -H "Content-Type: application/json" \
  -d '{
    "game_uuid": "7487f0fac9049c9ee0dd0635a8ce5f5bfe04cd15",
    "player_id": "test-user-123",
    "currency": "EUR"
  }'
```

### Option B: Using the UI

1. Go to `http://localhost:3000/casino`
2. Select a game
3. Click "Play" to start a session

---

## Step 6: Run Self-Validation

Call the self-validate endpoint:

```bash
curl -X POST "http://localhost:3000/api/casino/self-validate"
```

Or in browser:

```
http://localhost:3000/api/casino/self-validate
```

---

## Step 7: Check the Result

The response will look like:

```json
{
  "success": true,
  "status": 1,
  "log": ["All tests passed successfully"]
}
```

**OR if there are failures:**

```json
{
  "success": false,
  "status": 0,
  "log": [
    "bet request successfully passed",
    "Exceeding bet request should fail, but it's passed",
    "..."
  ]
}
```

## Troubleshooting

### Check if Active Session Exists

```bash
curl "http://localhost:3000/api/casino/self-validate"
```

Response should show:

```json
{
  "ready": true,
  "hasActiveSession": true
}
```

### View Server Logs

Check your terminal running `npm run dev` for detailed logs.

### Common Issues

| Issue                      | Solution                                   |
| -------------------------- | ------------------------------------------ |
| `hasActiveSession: false`  | Create a game session first (Step 5)       |
| Signature validation fails | Check MERCHANT_KEY is correct              |
| Callback not reaching      | Verify ngrok is running and URL is correct |

---

## What Slotegrator Tests

The self-validation runs these tests:

1. **Balance request** - Returns correct balance
2. **Bet request** - Correctly deducts balance
3. **Win request** - Correctly adds balance
4. **Insufficient funds** - Returns error ONLY (no balance/tx_id)
5. **Signature validation** - Rejects invalid signatures
6. **Refund** - Returns same transaction_id for duplicates
7. **transaction_id** - Generated by YOU, not using theirs
8. **Rollback** - Correctly reverses transactions

---

## Expected Response Format

### Success (status: 1)

```json
{
  "status": 1,
  "success": true,
  "log": ["All tests passed successfully"]
}
```

### Failure (status: 0)

```json
{
  "status": 0,
  "success": false,
  "log": [
    "bet request successfully passed",
    "Win with changed game uuid request successfully passed",
    "refund request without bet successfully passed",
    "bet request after refund successfully passed",
    "Exceeded bet request should fail, but it's passed",
    "..."
  ]
}
```
