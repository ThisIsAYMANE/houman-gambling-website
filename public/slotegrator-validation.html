🎮 Slotegrator Validation

Direct validation following Slotegrator protocol

ℹ️ Protocol: Launch game → Wait (don't touch) → Validate → Check for "failed" in results
1️⃣ Launch Game with /games/init
This will POST to /games/init and open the game in a new window.
2️⃣ Game Running - Don't Touch
The game has launched. Keep the game window open and don't click or interact with it. When ready, click the button below.
3️⃣ Send Validation Request
Send POST request to /self-validate endpoint.
4️⃣ Validation Results
